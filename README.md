# Dictionary Web Application

A responsive, modern, and interactive **Dictionary Web Application** that allows users to search for English words and view their meanings, example sentences, phonetic spellings, and audio pronunciations. The application uses the **Free Dictionary API** to fetch word data in real time.

🔗 **Live Demo:** https://soumya-1code.github.io/dictionary-web-application/

---

## 📌 Overview

This web application provides an intuitive interface for users to look up English words and receive:
- **Meaning** with part of speech
- **Example sentence** (auto-generated if API example is unavailable)
- **Phonetic spelling**
- **Audio pronunciation (if available)**
- **Dark mode toggle**
- Fully **responsive UI for mobile and desktop**

The app is built with pure **HTML, CSS, and JavaScript**, with a focus on clean design and accessibility.
